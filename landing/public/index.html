What is Tally?

See the Evidence Timeline

Tally sits between a voice agent's tool calls and the order it's about to place. It validates every extracted fact against independent evidence, holds anything it can't verify, and repairs it live, before a customer's correction gets lost.

Catches what the agent misses

An independent speech stream gives Tally its own evidence, so a correction the agent's own transcript dropped still gets caught.

Sub-second when it matters

The gate never waits when nobody's speaking. It only holds while there's a real correction in flight, and never past a bounded ceiling.

Nothing ships unverified

Every hold becomes a replayable case. Every config change has to pass the full regression suite before it can go live.
